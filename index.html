DeFiLoops (defiloops.com)

Go  |  agentic execution

The execution layer for multi-step DeFi. You describe a strategy in a sentence; it becomes a numbered plan you approve, and then runs for hours or days across networks, on an account only you can empty.

  • Six-stage compiler from conversation to signed transaction, where each stage narrows what is possible and any stage can refuse.
  • Steps that belong together are merged into one transaction, so an approval cannot outlive the step it was granted for; a step can spend what the previous step produced.
  • Atomic loan migration via flash loan: a deadlock by hand, one instruction here, with the borrowed funds never touching the user's account.
  • Key model enforced on-chain rather than by policy: the agent key signs typed adapter parameters with no field for a destination or raw calldata, is capped by a spend limit it cannot raise, and is revocable for every account on a chain in one transaction.
  • Own swap router answering questions an aggregator cannot: what fills at a named limit price, and how much a resting order takes right now.
  • Durable runs on Temporal, plus schedules, price triggers and plan chaining that rebuild and re-price the plan each time they fire.
  • Foundry invariant tests for the adversarial cases: agent blast radius, guard drain, proxy squatting, address parity.
Go Temporal Solidity Foundry ERC-4337 PostgreSQL go-ethereum Uniswap v3 Aave CCTP

MCP server for agent-driven DeFi

part of DeFiLoops

A Model Context Protocol server that lets a language model author, validate and run multi-step on-chain strategies, built to find out whether a small open model could write a plan the system would accept, and to make the answer yes.

  • 22 tools in five groups (catalogue, chain reads, plan authoring, chains and schedules, and run watching) over ~33k lines of Go with 84 test files.
  • Two transports with different guarantees: stdio, where a pipe's single reader makes unexposed tools structurally unreachable; and a loopback socket requiring a bearer token, refusing to bind anything but localhost.
  • Tools that spend money are withheld at the server unless explicitly enabled. On a pipe the client's request is a guarantee; on a socket it is only a preference.
  • Validation goes over the wire to the running API rather than importing the compiler, so the model validates against the build that will actually execute it.
  • Per-request credential binding on a value receiver, so two concurrent conversations cannot swap identities under load.
  • 21 written skill guides the agent reads before answering, held to one rule: a guide describes what the code does today, or it starts lying.
MCP Go JSON-RPC 2.0 LLM tool use OpenRouter

rapidzkey (github.com/asimashfaq/rapidzkey)

Open source  |  MIT

Fast Groth16 trusted setup for Circom circuits, a drop-in replacement for snarkjs groth16 setup producing byte-identical output.

  • 20–60× faster than snarkjs: a ~2M-constraint circuit drops from over an hour to about three minutes on eight cores.
  • Accumulates weighted curve points by scatter-add across Rayon threads, rather than running a separate MSM per signal.
  • Computes missing Lagrange-basis points by parallel IFFT, so unprepared ptau files work without a separate preparation pass.
Rust Rayon arkworks Groth16 BN254 Circom

Jarvis Network (jarvis.money)

2020 – present

A fully on-chain foreign exchange market. Jarvis Network's Synthereum protocol issues synthetic fiat currencies against collateral (jEUR, jCHF, jGBP, jMXN and others, collectively jFIATs), and jarvis.money is the application people trade them in.

  • Built the platform's trading interfaces in React and Next.js.
  • Synthereum's pools take a single asset instead of a pair, so roughly $10k of liquidity supports a $100k purchase at a 110% margin-hedging ratio, where a conventional AMM pool would need $200k.
  • The On-Chain Liquidity Router chains two pool swaps through a shared collateral, so a jFIAT↔jFIAT trade settles with zero price impact, and a jFIAT↔token trade carries only the impact its collateral would have carried.
  • That routing connects jFIATs to the entire on-chain liquidity of their collateral, with Paraswap, PicNic and Stableswap aggregated behind it.
  • FX prices come from Chainlink oracle networks; the protocols are governed by the Jarvis DAO and its JRT token.
  • Deployed across Ethereum, Polygon, BNB Chain, Gnosis Chain, Avalanche and Optimism, with trustless cross-chain routers moving jFIATs between them.
